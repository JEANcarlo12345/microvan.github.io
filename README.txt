MICROVAN — SITIO OFICIAL

ARCHIVOS PRINCIPALES
- index.html         -> página
- js/catalog.js      -> catálogo de álbumes y canciones
- js/app.js          -> reproductor y comportamiento
- assets/            -> portadas, logo y fotos
- music/             -> archivos MP3

PARA AGREGAR AUDIO
1. Crea una carpeta por álbum dentro de /music.
2. Copia los MP3 usando los nombres definidos en js/catalog.js.
3. Ejemplo:
   music/mejor-que-tu/01-mejor-que-tu.mp3
4. Abre js/catalog.js y agrega duración, letra y créditos.

No se incluyeron archivos de audio reales porque no fueron proporcionados.


MERCH
- Edita js/merch.js para cambiar productos, imágenes y enlaces.
- Cada producto tiene un campo url.
- Reemplaza la URL general de Mercado Libre por la publicación real de ese producto.

REPRODUCTOR
- El botón × cierra el reproductor y pausa el audio.
- El botón ♪ permite volver a abrirlo.
